# TerraEngine Website

A dark, modern landing page for the TerraEngine FNF engine.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — scroll reveal and mobile navigation

## GitHub Pages
1. Create a GitHub repository.
2. Upload these three files.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Customize
Replace the placeholder GitHub links in `index.html` with your repository and release links.
