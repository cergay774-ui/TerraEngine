# Звуки

Положите сюда файлы `.ogg` — игра возьмёт их вместо синтезированных кодом.
Если файла нет, звук генерируется автоматически.

| Файл | Где звучит |
|------|-----------|
| `engine.ogg` | общий звук мотора (бесшовная петля, высота тона меняется от оборотов) |
| `engine_<тип>.ogg` | звук конкретного мотора: `single`, `inline4`, `boxer`, `v6`, `v8`, `rotary`, `diesel`, `v12`, `radial`, `experimental` |
| `music.ogg` | фоновая музыка (петля) |
| `starter.ogg` | стартер «чих-чих» на экране загрузки |
| `knock.ogg` | стук мотора при перегреве |
| `turbo.ogg` | включение турбо |
| `crit.ogg` | критический газ |
| `coin.ogg` | выпал слиток / награда |
| `case_shake.ogg` | ящик трясётся |
| `case_open.ogg` | крышка слетает, запчасть вылетает |
| `fanfare.ogg` | «Новая эпоха!» |
| `click.ogg` | нажатие кнопки |
| `buy.ogg` | покупка |
| `garage_door.ogg` | гаражная дверь после загрузки |
| `rebirth.ogg` | перерождение |
