# Иконки

Положите сюда `.png` (квадратные, лучше 128×128 и больше) — они заменят векторные заглушки.

- Валюты: `cash.png`, `gold.png`, `diamond.png`, `emerald.png`, `sapphire.png`, `quantum.png`, `core.png`
- Кнопки нижней панели: `settings.png`, `upgrades.png`, `parts.png`, `shop.png`, `rebirth.png`

Иконка приложения — `game/icon.svg` (можно заменить на `icon.png` и поправить `config/icon` в `project.godot`).
