# Иконки

Здесь лежат иконки из присланных материалов (уменьшены и обрезаны по краям):

- Кнопки нижней панели: `settings.png`, `upgrades.png`, `parts.png` (гараж), `shop.png`, `rebirth.png`
- Ресурсы: `cash.png`, `gold.png`, `diamond.png`, `emerald.png`, `sapphire.png`, `quantum.png`
  (для ультра-ядер `core.png` картинки пока нет — рисуется векторная звезда)
- Улучшения: `upg_press.png`, `upg_stamina.png`, `upg_passive.png`, `upg_turbo.png`,
  `upg_cooling.png`, `upg_crit.png`, `upg_autogas.png`, `upg_offline.png`

Чтобы заменить иконку, положите файл с тем же именем. Плашка уровня — в `../ui/`
(`level_bg.png` — фон, `level_fill.png` — полоса опыта).
