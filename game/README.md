# Мотор Гараж — кликер-тайкун про сборку моторов

Игра по дизайн-документу: зажал двигатель — полный доход, отпустил — капает пассивный;
каждые 10 уровней — новая эпоха (тип мотора + материал), перерождения открывают новые валюты.
Godot 4.3, Android, портретная ориентация. Мотор целиком рисуется кодом (поршни, шатуны,
коленвал считаются по геометрии кривошипа), поэтому любой собранный мотор анимируется сам.

## Как получить APK

Каждый пуш в `game/` запускает GitHub Actions (`.github/workflows/android.yml`).
Готовый файл — во вкладке **Actions → последний запуск → Artifacts → motor-garage-apk**.
Это debug-APK: его можно сразу ставить на телефон (разрешите установку из неизвестных источников).

Release-APK для Google Play собирается, если в секретах репозитория заданы
`ANDROID_KEYSTORE_BASE64` (keystore в base64), `ANDROID_KEYSTORE_ALIAS`, `ANDROID_KEYSTORE_PASSWORD`.

## Как запустить на компьютере

Откройте папку `game/` в Godot 4.3 и нажмите F5. Мышь работает как палец.

## Своя графика и звуки

- Звуки `.ogg` → `game/assets/sounds/` (список имён — в README там же). Без файлов звук синтезируется кодом.
- Иконки `.png` → `game/assets/icons/`. Без файлов рисуются векторные заглушки.
- Все таблицы (улучшения, запчасти, моторы, материалы, эпохи, кейсы) — в `game/scripts/data.gd`.
  Новые детали и моторы добавляются там без переписывания остального кода.

## Структура

| Файл | Что внутри |
|------|-----------|
| `scripts/big.gd` | «Большое число» (мантисса + степень), держит 1e1000000 и дальше; форматы K, M, B … Dc, aa, ab … и 1.5e12 |
| `scripts/data.gd` | все таблицы игры |
| `scripts/game.gd` | экономика, стамина, турбо, криты, автогаз, запчасти, кейсы, ежечасовой магазин, задания, достижения, перерождения, ультра, сохранение и офлайн-доход |
| `scripts/engine_view.gd` | отрисовка и анимация всех 10 типов моторов, тряска, нагрев, пар, выхлоп, хлопки, турбина, рентген |
| `scripts/audio.gd` | звук мотора (бесшовный синтез, высота от оборотов), звуки событий, громкость |
| `scripts/boot.gd` | экран загрузки: гараж, поршень в разрезе, тахометр, подсказки, гаражная дверь |
| `scripts/main.gd` | главный экран, 5 кнопок, всплывающие числа и уведомления |
| `scripts/ui/*` | меню: улучшения, запчасти, магазин, перерождение, настройки, открытие кейса, «Новая эпоха!» |
