# Установка TechCore

Требуется **Minecraft Bedrock 1.26.50 или новее** (разработано под 1.26.52). Эксперименты и бета-API не нужны.

## Вариант 1 — готовый архив

1. Скачайте `TechCore/dist/TechCore.mcaddon`.
2. Откройте файл (двойной щелчок на Windows, «Открыть в Minecraft» на Android/iOS). Minecraft импортирует оба
   пакета: **TechCore BP** (поведение) и **TechCore RP** (ресурсы).
3. Создайте мир или откройте настройки существующего → **Пакеты поведения** → активируйте **TechCore**.
   Пакет ресурсов подключится автоматически (зависимость). Если нет — включите его в **Пакетах ресурсов**.
4. Экспериментальные функции включать не нужно.

Отдельные пакеты: `dist/TechCore_BP.mcpack` и `dist/TechCore_RP.mcpack` — если нужно обновить только один.

## Вариант 2 — папки для разработки (Windows)

Скопируйте папки в `com.mojang` (путь зависит от установки, обычно
`%APPDATA%\Minecraft Bedrock\Users\Shared\games\com.mojang`):

- `TechCore/behavior_pack` → `development_behavior_packs/TechCore_BP`
- `TechCore/resource_pack` → `development_resource_packs/TechCore_RP`

Пакеты из `development_*` перечитываются при каждом входе в мир — удобно для правок.

## Включение журнала контента

**Настройки → Создатель → Журнал ошибок контента: Вкл.** Сообщения TechCore начинаются с `[TechCore]`.
При запуске мира в логе должна появиться строка `[TechCore] Загружено машин: N` и `[TechCore] TechCore запущен`.

## Сборка из исходников

Нужны Node.js 22+ и Python 3.

```bash
cd TechCore
npm install          # типы Script API и TypeScript для проверки
npm run all          # генерация ресурсов → валидация → проверка типов → тесты → упаковка в dist/
```

Отдельные команды: `npm run build`, `npm run validate`, `npm run typecheck`, `npm test`, `npm run package`.

## Первые шаги в игре

1. Скрафтите **Железную шестерню** на верстаке: железо крестом, самородок в центре.
2. Скрафтите **Ультимативный сборщик Ур-0**: алмаз-шестерня-алмаз / золото-алмаз-золото / алмаз-шестерня-алмаз.
3. Поставьте сборщик и нажмите на него. Раздел **Рецепты** показывает всё, что можно собрать на уровне Ур-0:
   медный провод, угольный генератор, ветрогенератор I, корпус машины, аккумулятор, дробитель, электроплавильня,
   гаечный ключ, **инженерные очки** и управляющий модуль I.
4. Железные пластины и медные катушки на старте делаются на верстаке (дороже, чем на машинах).
5. Наденьте инженерные очки в слот шлема или возьмите во вторую руку и наведите взгляд на машину.
6. Гаечный ключ: нажатие по конвейеру поворачивает его; использование в воздухе открывает обзор/настройки TechCore.

Подробные рецепты — [RECIPES.md](RECIPES.md), баланс — [BALANCE.md](BALANCE.md).
