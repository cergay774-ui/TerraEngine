# Тестирование TechCore

## Что проверено автоматически (без запуска Minecraft)

Команда `npm run all` в папке `TechCore`:

| Проверка | Что гарантирует |
|---|---|
| `npm run typecheck` | все скрипты проверены TypeScript (`checkJs`, `strictNullChecks`) против **официальных** типов `@minecraft/server` 2.10.0 и `@minecraft/server-ui` 2.2.0: используются только существующие классы, методы, события и параметры этих версий |
| `tools/tests/logic.test.mjs` (21 тест) | виртуальные слоты (атомарность, отсутствие отрицательных количеств, сохранение суммы), рецепты и сетки, поиск путей и распределение энергии (приоритеты, потери, узкие места, аккумуляторы, простой генераторов), ветер, нагрев с гистерезисом, жидкости |
| `tools/tests/data.test.mjs` (10 тестов) | сетки уровней ровно 4×4, 5×4, 5×6, 7×7, 8×7, 9×9; каждый рецепт помещается в сетку своего уровня; все идентификаторы существуют; каждый предмет можно получить; **ни один компонент не открывается позже рецепта, которому он нужен**; модули модернизации доступны на предыдущем уровне; первый рецепт сборщика совпадает с ТЗ (5 алмазов, 2 золота, 2 шестерни); мощности ветрогенераторов 10/18/30/48/75 |
| `tools/tests/integration.test.mjs` (22 сценария) | настоящие скрипты аддона на имитации Script API: генератор питает дробитель; провод ограничивает мощность и даёт потери; ветрогенератор заряжает аккумулятор и крутит ротор; интерфейс сборщика загружает ровно недостающие ингредиенты и изготавливает рецепт; отмена возвращает резерв; модернизация Ур-0→Ур-1 без энергии не идёт, с энергией — меняет уровень и внешний вид, не трогая содержимое; сохранение/загрузка восстанавливает состояние; разрушение роняет содержимое и упакованный сборщик нужного уровня; установка упакованного сборщика восстанавливает уровень; **действие формы после разрушения машины ничего не выдаёт**; конвейер переносит из сундука в машину без потерь; ключ поворачивает ленту; переработчик → труба → биогенератор; бур добывает только природные блоки и не трогает сундук; очки показывают эффективность/потребление/выработку из слота шлема и второй руки; приоритеты при дефиците; пауза в выгруженном чанке; работа генератора на границе выгруженного чанка; кэширование сетей; отсутствие предупреждений скриптов |
| `npm run validate` | JSON корректен; UUID v4 уникальны; зависимости BP↔RP; точка входа скрипта существует; каждая геометрия, кость, материал, текстура, состояние в Molang-условиях существует и объявлено; все материалы блока используют один `render_method`; габариты моделей ≤ 30 px; UV внутри текстур; flipbook-ленты кратны кадру; `texture_set` ссылаются на существующие файлы; у каждого предмета есть иконка и перевод; кастомные компоненты блоков зарегистрированы в скриптах; все импорты скриптов существуют; все пути к иконкам интерфейса существуют |
| `npm run package` | архивы `.mcpack`/`.mcaddon` целостны, манифесты и иконки на месте |

Имитация API проверяет **логику скриптов**, но не движок: рендер моделей, парсинг JSON самим Minecraft,
работу форм на устройстве и производительность можно проверить только в игре.

## Ручная проверка в Minecraft Bedrock 1.26.52

Включите журнал контента (см. [INSTALLATION.md](INSTALLATION.md)). Создайте мир в творческом режиме с читами.

### Загрузка
- [ ] Мир открывается без ошибок `[TechCore]` и ошибок JSON в журнале контента.
- [ ] В журнале: `Загружено машин: 0`, `TechCore запущен`.
- [ ] Все блоки и предметы TechCore есть в творческом инвентаре с иконками и русскими названиями.

### Этап 1 — сборщик Ур-0
- [ ] Рецепт шестерни и сборщика работает на верстаке (книга рецептов показывает их после получения шестерни/железа).
- [ ] Сборщик ставится, смотрит на игрока, у него видны экран, светодиод, портал с головкой.
- [ ] Нажатие открывает меню; «Рецепты» → «Угольный генератор» показывает сетку, легенду, «есть/нужно».
- [ ] «Загрузить ингредиенты на ×1» забирает ровно нужное; «Изготовить ×1» → через ≈12 с результат в выходе.
- [ ] «Забрать результат» при полном инвентаре оставляет остаток в машине.
- [ ] Выход из мира и повторный вход: содержимое хранилища, очередь, прогресс сохранены.

### Этап 2 — энергия
- [ ] Угольный генератор + уголь: огонь в топке анимирован, светодиод зелёный, блок светится.
- [ ] Дробитель рядом с генератором работает; без генератора — «Нет энергии», красный светодиод.
- [ ] Медный провод соединяется с соседями (рукава модели), длинная линия даёт потери (видно в очках).
- [ ] Ветрогенератор I ставится в 2 блока высотой, ротор вращается; на Y≈140 выработка выше, чем у моря;
      окружённый блоками — ниже. В Незере — «Нет ветра».
- [ ] Аккумулятор заряжается излишком (полосы на передней панели растут) и отдаёт энергию без генератора.
- [ ] Угольный генератор под постоянной нагрузкой через ≈2,5 мин уходит в «Перегрев» (половина мощности);
      две соседние водяные клетки предотвращают перегрев.

### Этап 3 — производство
- [ ] Цепочка: рудное железо → дробитель → пыль → плавильня → слитки → пресс → пластины → станок → шестерни.
- [ ] Головка пресса двигается вверх-вниз, шпиндель станка и валки дробителя анимированы.
- [ ] При заполненном выходе машина показывает «Выход заблокирован» и не теряет предметы.

### Этап 4 — транспорт и топливо
- [ ] Конвейер ставится по направлению взгляда; ключ поворачивает его; лента анимирована; груз виден.
- [ ] Сундук → конвейер → машина → конвейер → сундук: предметы не теряются и не дублируются.
- [ ] Фильтр: подходящее вперёд, остальное вправо; разветвитель делит поток по очереди.
- [ ] Буровая установка добывает колонну 3×3 вниз, не трогает сундуки/постройки, глубина растёт; бур двигается.
- [ ] Переработчик: 4 биомассы → 500 мБ биотоплива; труба доставляет топливо в биогенератор и резервуар.
- [ ] Канистры наполняются из резервуара и сливаются в генератор.

### Этап 5 — модернизация
- [ ] Ур-0→Ур-1: без энергии «Нет энергии», с генератором — прогресс; после завершения меняется модель
      (кабельные лотки), сетка 5×4, новые рецепты; содержимое сохранено.
- [ ] Перезапуск мира во время модернизации сохраняет прогресс.
- [ ] Разрушенный Ур-1 выпадает как «Ультимативный сборщик Ур-1», при установке уровень восстанавливается.
- [ ] Ур-5 показывает светящееся ядро.

### Очки инженера
- [ ] Очки надеваются в слот шлема и видны на голове.
- [ ] При взгляде на машину строка действия показывает эффективность и потребление, на генератор — выработку,
      на провод — пропускную способность и сводку сети. Во второй руке тоже работает.

### Мультиплеер
- [ ] Два игрока одновременно открывают одну машину: результат забирает только один, у второго — «Пусто».
- [ ] Разрушение машины, пока у другого игрока открыта форма: последующее действие формы ничего не выдаёт.

### Vibrant Visuals
- [ ] При включённом Vibrant Visuals блоки не чёрные/не розовые, металл бликует, индикаторы и экраны светятся.
- [ ] Роторы ветрогенераторов прозрачны вокруг лопастей, без мерцания.

### Производительность (мобильное устройство)
- [ ] 30–50 машин и 100+ проводов в одной базе не дают заметных фризов; при необходимости уменьшите радиус и
      лимит анимаций, отключите груз на конвейерах в настройках (ключ в воздухе).

Если что-то не работает, пришлите строки журнала контента с префиксом `[TechCore]` и ошибки JSON.
